# Senegambia Way

Private browser capture of Lagos Life used as technical reference for building **Senegambia Way**, a Gambian life-simulation world.

## Current design pass

The capture remains preserved as the reference source. Gambian localization is being layered on top rather than rewriting the original evidence.

### Added
- `senegambia-world-localization.json` — Gambian geography, place mapping, transport, institutions, food, language, money and worldbuilding rules.
- `senegambia-visible-text.txt` — first-pass localized labels and landing-page copy.

### Geography direction
- **Serrekunda** — affordable everyday/commercial core, market and transport.
- **Banjul** — capital, government, courts, historic landmarks and ferry connection.
- **Bakau / Fajara** — coastal residential, sports and leisure.
- **Kotu / Kololi / Senegambia** — tourism, nightlife, hotels, restaurants and beach.
- **Sukuta / Bijilo / Brufut** — expanding residential/suburban belt.
- **Brikama** — regional market, crafts and West Coast town life.

The next source-level implementation should apply these mappings to the actual game frontend/backend while preserving existing gameplay mechanics.

## Reference material

The original `lagoslife_snapshot/` and network captures are intentionally retained as reverse-engineering/reference material and should not be treated as the final Gambian copy.
